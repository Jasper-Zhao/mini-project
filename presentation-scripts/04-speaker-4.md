# Speaker 4 — Slides 10–11

Estimated time: 2 minutes

## Slide 10 — The road ahead builds on a stable core

The current version is a stable working vertical slice. The next stage would be identity and team support, including authentication, an employee directory, and ownership checks so that users can manage only their own bookings.

Later, the project could support recurring reservations, calendar integration, and usage analytics. Those features would add convenience at a larger scale, while keeping the same booking integrity rule at the center of the system.

## Slide 11 — Thank you

To conclude, DeskFlow provides a focused way for Helsinki office employees to find, book, and release a desk for a specific day.

The project combines a browser interface, a Spring Boot REST API, explicit JDBC persistence, and MySQL constraints to make the core booking flow reliable.
