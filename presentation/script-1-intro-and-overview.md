## 3. Our Project — DeskFlow

We built **DeskFlow**: a hot desk booking system for the Helsinki office.

The problem is straightforward. Open-plan offices have desks that nobody permanently owns. Right now employees have no reliable way to know which desks are free on a given day. They arrive, find their usual spot taken, or discover the desk they expected to have a monitor doesn't. The process is chaos — spreadsheets, sticky notes, Slack messages.

DeskFlow fixes this with a REST API and a browser UI that anyone can open on any device, with nothing to install.

### What it does

| Feature | Description |
|---|---|
| Browse desks | Filter the full desk catalogue by floor or monitor |
| Check availability | Instantly see which desks are free on a chosen date |
| Book a desk | Reserve a desk for yourself by name |
| Cancel a booking | Free the desk if your plans change |
| Prevent double-booking | One desk, one booking, per day — enforced at every layer |

- **10 desks** across Floors 2, 3 and 4 — a mix of monitor / no-monitor setups, one marked inactive
- **4 sample bookings** pre-loaded so the demo works immediately without any manual setup
